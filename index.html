💜Skym深鱼拼图 v1.9.6 · 使用说明💜

【基础操作】

  • 清空：一键清空全部图片
  • 加图：点击添加图片（支持多选）
  • 删除：每张图片右上角×可单独删除
  • 替换：点击已有图片可替换新图

【下载方式】

  • 3x3：九宫格分割，每9张生成一张图批量导出
  • 单张：弹窗选择——全部打包ZIP / 指定序号下载（支持如“1,3,5-8,2”多选）
  • 长图：全部图片拼成一张长图下载
  • 输出质量：原图PNG / 高清JPG / 压缩JPG（在顶部工具栏选择）

【图片拖拽】（bug，暂时取消）

  • 拖拽图片可互换位置，拖拽时显示浮动预览图
  • 拖到空白区域可取消操作

【水印设置】

  • 点击「水印」上传水印图片
  • 勾选「启用」显示/隐藏水印
  • 数字框调整水印大小
  • 按住水印可拖拽移动位置

【序号设置】

  • 勾选「序号」显示/隐藏序号
  • 「从X开始」自定义起始编号（如1、10、101）
  • 下拉框可改序号字体
  • 数字框调整序号文字大小
  • 色块可改序号颜色
  • 按住序号数字可拖拽移动位置

【画布设置】

  • 行选择：1行~7行
  • 比例：1:1 / 3:4 / 9:16 / 4:3 / 16:9
  • 模式：裁剪/完整

【其他功能】

  • 图片数量：左侧显示当前已添加X张图片
  • 主题颜色：点击🎨可切换界面颜色（粉/蓝/绿/紫/橙/灰/深色等）
  • 自动保存：退出后自动恢复图片、水印、序号、主题等所有设置
  • 水印/序号位置：拖拽后可自动记忆位置
  • 图片数量：建议50张，避免遗漏图片
